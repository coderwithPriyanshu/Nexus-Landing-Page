# Nexus — Responsive Landing Page

A responsive student technology community landing page built for the Technical Team Web Development task.

## Features

- Sticky responsive navigation
- Mobile hamburger menu
- Hero section with CTA
- Feature cards with hover/entrance animations
- Community statistics
- Auto-rotating testimonial carousel with manual controls
- Glassmorphism UI
- Smooth section navigation
- Responsive mobile/tablet/desktop layouts
- Accessible button labels and semantic sections

## Tech Stack

- React 18
- Vite
- HTML5
- CSS3

## Run locally

```bash
npm install
npm run dev
```

For production:

```bash
npm run build
npm run preview
```

## Deployment

Recommended: Vercel.

1. Push this folder to a public GitHub repository.
2. Import the repository into Vercel.
3. Use the project root as the root directory.
4. Build command: `npm run build`
5. Output directory: `dist`
